# Common Backend for Projects

This project is a **common backend** designed to serve as a unified backend for multiple applications, avoiding the need to develop a separate backend for each project. By centralizing backend logic, maintenance, scalability, and development efficiency are improved.

Currently, this backend serves the following projects:

## Spotify
- [Spotify Angular](https://github.com/Doplax/Spotify-Angular)

## NodePop
- [NodePop Frontend (React)](https://github.com/Doplax/NodePop-Frontend)
- [NodePop Frontend (Vanilla)](https://github.com/Doplax/NodePop-JavaScript)
- [NodePop Backend (Express)](https://github.com/Doplax/NodePop-Backend)

## GPT
- [AngularGPT-FrontEnd](https://github.com/Doplax/AngularGPT-FrontEnd)
- [NestGPT-BackEnd (Nest)](https://github.com/Doplax/NestGPT-BackEnd)

## HMI Car Play
- [HMI-CarPlay-Angular](https://github.com/Doplax/HMI-CarPlay-Angular)
